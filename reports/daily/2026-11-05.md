## 🤖 로보틱스

- **Next Gen Open-RMF Behavior Declarations**: 모듈 구현체가 매니페스트 파일 등을 통해 기능과 동작을 공식적이고 확장 가능한 방식으로 선언하도록 지원하는 Behavior Declarations 개념을 도입합니다 [<a href="#ref-1">1</a>].
- **ROS Central Registry lyrical.2026-10-05.rcr.0**: ROS Central Registry 새 릴리스가 공개되었으며, MoveIt, Nav2, Gazebo 등을 포함한 패키지와 Linux 및 macOS 플랫폼 빌드를 지원합니다 [<a href="#ref-2">2</a>].
- **차기 ROS 2 Makoa Mata-mata 관리자 선정**: 차기 ROS 2 Makoa Mata-mata 릴리스 관리를 위해 Christophe Bédard가 6개월 이상 앞서 ROS Boss로 지정되었습니다 [<a href="#ref-3">3</a>].
- **Liber-0 월드 액션 모델**: LiberAI가 220만 시간 이상의 인간 경험 데이터로 사전학습된 월드 액션 모델 Liber-0을 공개하고, GPT-6 기반 60개 제로샷 평가 작업에서 36.0% 성공률을 보고했습니다 [<a href="#ref-4">4</a>].
- **병원용 UV 소독 AMR 개발**: GlobalLogic이 Haystack Robotics와 협력하여 ROS 기반 프로그래밍과 센서 퓨전을 적용한 자율 이동 소독 로봇 플랫폼을 구축했습니다 [<a href="#ref-5">5</a>].

## ✨ AI

- **OpenAI Linux 커널 패치 자율 파이프라인**: Linux 커널에서 948개의 로컬 권한 상승 취약점을 탐지, 검증하고 패치를 자동 생성하는 자율 파이프라인 구축 결과를 발표했습니다 [<a href="#ref-6">6</a>].
- **OpenAI Daybreak Red (AWS GovCloud)**: Amazon Bedrock을 통해 AWS GovCloud (US-East)에서 인가된 사이버보안 업무용 GPT-5.6 Cyber를 승인된 고객 대상으로 제공합니다 [<a href="#ref-7">7</a>].
- **Google Antigravity용 Cheminformatics Skills**: Google DeepMind가 RDKit, ChEMBL, PubChem 기반 화학정보학 도구 모음을 Google Antigravity에 출시하여 화합물 검색 및 강직화 거대고리 화합물 설계를 지원합니다 [<a href="#ref-8">8</a>].
- **Ripple-65B Preview 모델**: Ricursive Intelligence가 12조 토큰으로 사전학습되고 최대 100만 토큰 컨텍스트를 지원하는 오픈웨이트 코딩 모델을 발표했으며, TerminalBench 2.1에서 80.52를 기록했다고 밝혔습니다 [<a href="#ref-9">9</a>].
- **Model Context Protocol 서버 모음 v2.3.0**: server-filesystem 2.2.0(append_file, copy_file, --read-only 모드 추가), server-memory 2.1.0 등 핵심 MCP 서버가 배포되었습니다 [<a href="#ref-10">10</a>].
- **LiteLLM v1.108.0**: 네이티브 Vertex AI Interactions API 지원을 추가하고, /v1/rag/ingest 업로드 보안 제어 및 cosign 기반 컨테이너 서명 검증을 적용했습니다 [<a href="#ref-11">11</a>].
- **Anthropic Python SDK v2.5.0**: HTTP 상태 및 API 에러 코드 클래스 세분화, 워크스페이스 ids 필터 추가, Bedrock/Vertex 경로 유효성 검사 및 인코딩 버그를 수정했습니다 [<a href="#ref-12">12</a>].
- **datasette-apps 0.3a0**: Datasette Agent 채팅의 '#' 태그 자동완성, app_add_stored_queries() 도구 및 쓰기 쿼리 사용자 승인 검사 기능을 추가했습니다 [<a href="#ref-13">13</a>].
- **datasette-agent 0.5a0**: Datasette 테이블이나 쿼리 페이지 옆에 에이전트 채팅창을 나란히 배치하여 datasette-apps와 연동 가능한 패널(panel) 기능을 도입했습니다 [<a href="#ref-14">14</a>].

## 📈 트렌드

- **OpenAI의 Pierre Computer Company 인수**: OpenAI가 코드 작성, 이해 및 검토를 위한 Codex 도구 역량을 확장하기 위해 Pierre Computer Company를 인수한다고 발표했습니다 [<a href="#ref-15">15</a>, <a href="#ref-16">16</a>].
- **배달 드론 소음 갈등 및 환경 규제 소송**: Amazon Prime Air, Wing, Zipline 등의 배달 드론 운용 확대에 따라 로터 소음 불만이 제기되는 가운데, 15개 주와 텍사스주 해리스 카운티가 FAA의 드론 기지 환경 평가 규칙 완화에 반대하는 소송을 제기했습니다 [<a href="#ref-17">17</a>].
