## 💡 오늘의 관찰

- 로보틱스 도메인에서는 ROS 2 환경의 실시간 토픽 모니터링과 AI 정책 연결 등 실무 런타임 최적화가 지속되고 있습니다.
- 고성능 추론 하드웨어와 새로운 모델들이 에이전틱 워크로드를 겨냥하여 전력 효율 및 토큰 생성 속도를 크게 개선하고 있습니다.
- 휴머노이드 로봇에 대한 대규모 투자와 하드웨어 진화가 AI 학습 모델의 실제 로봇 적용 흐름과 맞물려 가속화되고 있습니다.

---

## 🤖 로보틱스

- **Ros2_pulse**: 기존 바이너리 변경 없이 intra-process를 포함한 토픽별 전송률 및 노드 생존 여부를 모니터링하는 프로브 릴리스 [<a href="#ref-1">1</a>]
- **lerobot-robot-ros2-zenoh SDK**: Hugging Face LeRobot 학습 정책을 실제 로봇에 신속하게 배포하고 연결하는 오픈소스 SDK 공개 [<a href="#ref-2">2</a>]
- **Aeron Systems Pollux 3**: 자율 이동 로봇 및 무인 이동체를 위한 GNSS 보조 INS(관성 내비게이션 시스템) 전용 ROS 2 드라이버 연동 지원 [<a href="#ref-3">3</a>]

---

## ✨ AI

- **GPT‑5.6 in Kiro**: Kiro 도구에서 향상된 가격 대비 성능으로 소프트웨어 계획, 개발, 리뷰, 테스트를 지원하는 GPT-5.6 모델 제공 [<a href="#ref-4">4</a>]
- **llm-anthropic 0.27**: 최신 Anthropic Python SDK와의 호환성을 제공하는 LLM 도구용 Anthropic 플러그인 업데이트 [<a href="#ref-5">5</a>]
- **Claude Code skill**: 내보내기가 차단된 Kindle 하이라이트를 복구할 수 있는 Claude Code 전용 확장 스킬 공개 [<a href="#ref-6">6</a>]
- **LLM Inference Engine Exploitation**: LLM이 추론 엔진의 취약점을 악용하여 호스트 머신을 제어할 수 있는 보안 가능성 제시 [<a href="#ref-7">7</a>]
- **PicoMQ**: 객체 스토리지를 기반으로 HTTP 상에서 동작하는 내구성 스트리밍 메시지 큐 공개 [<a href="#ref-8">8</a>]

## 📈 트렌드

- **IEEE Spectrum Video Friday**: 초인적 능력을 발휘하는 휴머노이드 로봇의 기술 진화와 활용성을 조명하는 로보틱스 비디오 큐레이션 [<a href="#ref-9">9</a>]
- **Dogotix 9억 달러 투자 유치**: 샤오펑 모터스의 휴머노이드 로봇 자회사 Dogotix가 대규모 양산을 목표로 9억 달러 투자를 유치하며 기업가치 63억 달러 달성 [<a href="#ref-10">10</a>]
- **NVIDIA Vera Rubin LPX**: 에이전틱 시스템의 빠른 토큰 생성을 지원하기 위해 Groq 3 LPX를 생산 단계에 통합하고 랙 스케일 추론 확장 발표 [<a href="#ref-11">11</a>]
- **NVIDIA Vera Rubin NVL72**: 에이전틱 AI 워크로드를 위해 와트당 최대 30배 높은 작업 효율을 제공하는 신규 시스템 표준 발표 [<a href="#ref-12">12</a>]
