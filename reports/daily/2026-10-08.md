## 💡 오늘의 관찰

- 해석: 상용 모델 공급사가 대규모 작업 처리를 위해 토큰 단가를 낮춘 경량 모델을 지속 투입하고 있음에도, 주요 빅테크 기업들은 누적되는 개발 보조 도구 비용을 통제하고자 자체 모델 기반 도구로의 전환을 본격화하고 있습니다 [<a href="#ref-1">1</a>, <a href="#ref-2">2</a>].

---

## 🤖 로보틱스

- **Rokoko Smartgloves II ROS 2 브릿지**: Rokoko가 Smartgloves II의 손 추적 데이터를 ROS 2로 네이티브 발행하는 Apache 2.0 라이선스 오픈소스 브릿지를 공개했으며, ROS 2 Lyrical Luth 및 Rokoko Device SDK 0.10.0 이상 환경에서 26개 관절 포즈와 TF 변환, RViz 시각화 기능을 제공합니다 [<a href="#ref-3">3</a>].

---

## ✨ AI

- **Anthropic Claude Haiku 5.5 및 SDK 지원**: Anthropic이 대규모 고빈도 작업용 경량 모델 Claude Haiku 5.5를 출시하여 10만 토큰 이하에서 입력 0.10달러·출력 0.50달러로 가격을 낮췄으나 새 토크나이저로 프롬프트당 토큰 소모량이 늘어날 수 있으며, Python SDK v1.12.0에 모델 호출과 컴퓨터·브라우저 도구 지원이 추가되었습니다 [<a href="#ref-4">4</a>, <a href="#ref-1">1</a>, <a href="#ref-5">5</a>].
- **llm-openai-decisions 플러그인**: Simon Willison이 OpenAI Decisions API 규격을 로컬 LLM CLI 환경에서 활용할 수 있도록 텍스트와 이미지 입력을 처리하는 오픈소스 플러그인을 공개했습니다 [<a href="#ref-6">6</a>].
- **MySQL용 TidesDB 스토리지 엔진**: MySQL v9 및 v26 환경에서 소스코드 포크 없이 플러그인으로 로드하여 사용 가능하며, 값 분리(Value Separation)와 낙관적 MVCC를 통해 대용량 쓰기와 저장 공간을 최적화한 LSM 기반 스토리지 엔진이 출시되었습니다 [<a href="#ref-7">7</a>].
- **엔비디아·마이크로소프트 RTX Spark 및 실행 컨테이너**: 엔비디아와 마이크로소프트가 최대 128GB 통합 메모리 기반으로 윈도우 PC에서 로컬 모델을 구동하는 RTX Spark 하드웨어와 에이전트를 OS 수준에서 관리하는 Microsoft Execution Containers(MXC)를 공개했습니다 [<a href="#ref-8">8</a>].

## 📈 트렌드

- **빅테크 기업 내부 Claude AI 사용 축소**: 메타와 마이크로소프트가 AI 도구 비용 통제 및 자체 개발 도구 채택 확대를 위해 내부 직원 대상의 Claude AI 사용 한도를 대폭 축소하거나 전용 툴로 전환을 유도하고 있습니다 [<a href="#ref-2">2</a>].
- **슈나이더 일렉트릭의 PTC 인수 합의**: 슈나이더 일렉트릭이 제품 설계부터 현장 운영까지 이어지는 디지털 스레드 구축과 산업 자동화 경쟁력 강화를 위해 산업 설계·PLM 기업 PTC를 약 226억 달러에 인수하기로 합의했습니다 [<a href="#ref-9">9</a>].
- **테라다인 로보틱스-엘리트 로봇 협동로봇 분쟁 합의**: 테라다인 로보틱스와 엘리트 로봇이 Universal Robots 소프트웨어 저작권 침해 혐의로 진행되던 독일 법원 소송을 책임 인정 없이 비공개 조건으로 상호 합의 종결했습니다 [<a href="#ref-10">10</a>].
