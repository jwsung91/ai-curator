## 🤖 로보틱스

- **BLDC 모터 및 액추에이터 선정 가이드**: 로봇 팔 및 모바일 로봇을 위한 BLDC/PMSM 모터 선정 시 단순 전압·출력 사양 대신 기계 부하 계산, FOC 및 정류 제어 방식, 모터축과 감속기 출력축의 엔코더 배치, 회생 제동 수용성을 종합적으로 고려해야 합니다 [<a href="#ref-1">1</a>].

## ✨ AI

- **Claude Code 팀의 지속적 AI 코드 리뷰 워크플로**: PR 제출 시점 검사에만 의존하지 않고 코드 작성 과정에서 Claude가 1차 검토와 수정을 상시 수행해 일상적인 오류를 거르고 고차원적 검토에 집중하는 워크플로를 적용합니다 [<a href="#ref-2">2</a>].
- **URL 프래그먼트 기반 클라이언트 사이드 LaTeX 렌더러**: MathJax 및 faster-latex를 사용해 수식과 문서를 실시간 렌더링하며, 문서 데이터를 URL 프래그먼트에 압축 저장하고 XSS 방지를 위해 iframe 샌드박스를 적용한 웹 도구가 공개되었습니다 [<a href="#ref-3">3</a>].
- **Hybrid Reasoning Agents**: HybridLink와 작업 메모리를 통해 텍스트와 잠재 공간(latent space) 추론 간 전환을 지원하는 HybridAgent 연구에서 11개 벤치마크 기준 10.4% 성능 개선과 35.5%~54.7% 토큰 절감을 보고했으며 오픈소스 코드와 데이터를 공개했습니다 [<a href="#ref-4">4</a>].
- **KillSwitch**: LLM과 코딩 에이전트의 코드 이해 능력 및 취약점을 검증하기 위해 문자 수 기반 실행 규칙과 가드레일 자극 구문을 포함한 스택 기반 해석 언어 KillSwitch의 인터프리터와 벤치마크를 오픈소스로 공개했습니다 [<a href="#ref-5">5</a>].
- **DeepSeek Search 및 Fetch API**: 구조화된 검색 결과를 반환하는 Search API와 웹페이지를 마크다운으로 추출하는 Fetch API를 정식 출시했으며, 각각 성공 요청 1,000건당 0.75달러 과금 기준과 계정당 초당 5 QPS 제한을 적용합니다 [<a href="#ref-6">6</a>].
- **Ollama v0.40.6**: Windows 환경에서 고립된 러너 프로세스 발생을 방지하고 GGUF q2_0 텐서 및 파일 타입을 추가 지원합니다 [<a href="#ref-7">7</a>].
- **LiteLLM v1.106.0**: Docker 이미지 배포 시 cosign 암호화 서명 검증을 도입하고 보안 강화를 위해 stdio 기반 MCP 서버를 기본 비활성화했습니다 [<a href="#ref-8">8</a>].
