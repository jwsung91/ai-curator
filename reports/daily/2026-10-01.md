## 💡 오늘의 관찰

- 해석: Ollama의 Jev API 기반 결정 모델 엔드포인트 도입과 OpenAI의 Decisions API 공개는 에이전트 환경에서 전체 텍스트 생성 대신 사전 정의된 선택지와 확률만을 신속히 반환받아 모델 라우팅 및 분류의 지연 시간과 비용을 줄이려는 흐름을 보여줍니다 [<a href="#ref-1">1</a>, <a href="#ref-2">2</a>].

---

## 🤖 로보틱스

- **ROS PMC 회의: REP 158 OpenUSD 규약 통과**: 시뮬레이션 자산 상호운용성을 위한 OpenUSD 표준 규약인 REP 158이 공식 통과되었으며, 빌드팜 타임아웃 해결 및 macOS 배포 방안 등이 논의되었습니다 [<a href="#ref-3">3</a>].
- **ANYbotics Shift**: 4족 보행 로봇 ANYmal 등의 점검 플릿 관리, 실시간 플랜트 디지털 트윈 매핑, 이상 감지 데이터를 ERP 및 CMMS 작업 지시서로 자동 변환하는 산업용 통합 운영 플랫폼이 출시되었습니다 [<a href="#ref-4">4</a>].

---

## ✨ AI

- **OpenAI DevDay 2026 에이전트 인프라 공개**: OpenAI의 발표에 따르면 Astra 수준 지능을 표방하며 토큰 단가를 5분의 1로 낮춘 GPT-6.1 Sol이 공개되었고, 초당 최대 300토큰을 지원하는 Ultrafast 모드 및 오픈소스 CLI를 포함한 Codex Security Cloud가 발표되었습니다 [<a href="#ref-5">5</a>, <a href="#ref-1">1</a>].
- **Photo Scrubber**: Google MediaPipe C++ 라이브러리를 WebAssembly로 컴파일하고 BlazeFace 모델을 결합하여 외부 서버 전송 없이 브라우저 로컬에서 얼굴 감지 및 블러 처리를 수행하는 실험 도구입니다 [<a href="#ref-6">6</a>].
- **Google Gemini 4 Argon**: 장기 추론과 소프트웨어 엔지니어링 및 보안 패치에 맞춰 출력 한도를 기존 64K에서 최대 100만 토큰으로 확장했으며, Fairwind 프로그램을 통해 사이버 보안 담당자 대상의 단계적 배포를 시작했습니다 [<a href="#ref-7">7</a>].
- **Magnitude 에이전트 추론 엔진**: 사용자 기기에서 커널을 직접 컴파일하고 튜닝하여 오픈 모델 디코딩 속도를 높이고 세션 간 접두사 캐시를 공유하는 오픈소스 에이전트 추론 엔진입니다 [<a href="#ref-8">8</a>].
- **Anthropic Python SDK v1.11.0**: API 지출 한도 목록을 조회하는 신규 엔드포인트가 추가되었고 클라이언트 라이브러리 내 Sonnet 4.5 지원 중단 처리가 반영되었습니다 [<a href="#ref-9">9</a>].
- **Ollama v0.35.0**: TypeSafe의 Jev API를 기반으로 텍스트 대신 선택지, 확률, 점수를 반환하는 결정 모델 전용 엔드포인트(/v1/systemone)가 추가되었습니다 [<a href="#ref-2">2</a>].
- **CoreWeave 인프라 및 Forge 공개**: 에이전트 격리 환경 구동을 위한 Vera CPU와 NVIDIA Vera Rubin NVL72 시스템의 클라우드 가용성이 발표되었으며, 모델 평가와 강화학습 루프를 통합한 CoreWeave Forge 플랫폼이 출시되었습니다 [<a href="#ref-10">10</a>].

- **미국 FTC, 주요 AI 기업 대상 위험성 조사 착수**: 미국 연방거래위원회(FTC)가 OpenAI와 Anthropic 등 인공지능 기업들이 개발한 제품의 잠재적 위험성과 안전성 관리 관행에 대한 공식 조사에 착수했습니다 [<a href="#ref-11">11</a>].
