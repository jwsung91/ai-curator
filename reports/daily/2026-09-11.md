## 💡 오늘의 관찰

- ROS 2 개발용 엔지니어링 가이드와 최신 LLM 에이전트 SDK의 진화는 로보틱스 소프트웨어 스택 전반에서 자율 코딩 에이전트의 활용 가능성을 높이고 있습니다.
- 실제 하드웨어 배포 전 시나리오 결함 주입 프레임워크와 산업 현장의 ROS 2 기반 자동화 적용은 미들웨어의 안전성 및 신뢰성 검증의 중요성을 강조합니다.
- 비디오 기반 단일 학습 모델과 로보택시 오픈 플랫폼 등 NVIDIA 기반 피지컬 AI 기술이 복잡한 작업 자동화와 상용 플릿 확장을 주도하고 있습니다.
- 정밀 조작을 위한 촉각 센서 데이터 수집과 로봇 하드웨어 핵심 인터페이스 관련 특허 분쟁은 물리적 구현 영역의 기술 장벽이 고도화되고 있음을 보여줍니다.

---

## 🤖 로보틱스

- **ros2_fault_injection**: ROS 2 토픽 및 서비스를 프록시하여 통제된 결함을 주입하고 하드웨어 배포 전 자율주행 스택을 사전 검증하는 C++ 프레임워크 공개 [<a href="#ref-1">1</a>]
- **ros2-engineering-skills**: Claude Code 및 Codex 등 코딩 에이전트의 개발 정밀도를 높이기 위한 ROS 2 엔지니어링 가이드 및 검증 도구 v1.5.0 릴리스 [<a href="#ref-2">2</a>]
- **rosbag2**: ROS 2 공식 데이터 로깅 및 재생 패키지의 버그 수정 패치 v0.33.4 릴리스 [<a href="#ref-3">3</a>]

---

## ✨ AI

- **OpenAI Agents API**: 자율 워크플로우 구축 및 에이전트 오케스트레이션을 지원하는 공식 에이전트 API 가이드 제공 [<a href="#ref-4">4</a>]
- **Anthropic SDK v1.5.0**: Managed Agents용 자동 도구 권한 부여 및 인증 없는 공개 GitHub 저장소 마운트 기능이 추가된 Python SDK 릴리스 [<a href="#ref-5">5</a>]
- **Ollama v0.34.0**: ChatGPT Desktop 환경 연동 및 Apple Silicon 상의 구조화 출력 성능을 개선한 로컬 모델 런타임 업데이트 [<a href="#ref-6">6</a>]
- **LiteLLM v1.100.1**: Cosign 기반 불변 커밋 해시 검증을 도입하여 배포 신뢰성을 높인 도커 이미지 보안 업데이트 [<a href="#ref-7">7</a>]

## 📈 트렌드

- **Skild AI**: 단일 비디오 시연만으로 복잡하고 장기적인 작업을 학습할 수 있는 NVIDIA 피지컬 AI 기반 S1 파운데이션 모델 발표 [<a href="#ref-8">8</a>]
- **NVIDIA Robotaxi Platform**: 글로벌 자율주행 로보택시 상용 플릿 확장을 가속화하는 풀스택 오픈 플랫폼 전략 공개 [<a href="#ref-9">9</a>]
- **Comau**: ROS 2 소프트웨어 아키텍처와 AI 비전 시스템을 결합한 MyCo 코봇 기반 데카슬론 물류 자동화 구축 [<a href="#ref-10">10</a>]
- **Swarmer**: 우크라이나 지상 무인 차량(UGV) 제조사 Ratel Robotics를 최대 2억 2,400만 달러에 인수하여 군집 로봇 플랫폼 확대 [<a href="#ref-11">11</a>]
- **Teradyne Robotics**: Universal Robots의 인터페이스, 안전 브레이크, 조인트 관련 특허 3건 침해를 이유로 JAKA 상대 소송 제기 [<a href="#ref-12">12</a>]
- **IEEE Spectrum 촉각 기술 분석**: 로봇의 정밀 조작(dexterous manipulation) 한계를 극복하기 위한 양질의 촉각 데이터 수집 동향 조명 [<a href="#ref-13">13</a>]
