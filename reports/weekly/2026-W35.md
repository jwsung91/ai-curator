## 🗓 이번 주 핵심 흐름

- ROS 2 Jazzy 중심의 런타임 제어기 확장, 레거시 마이그레이션 브리지, 빌드 및 센서 통합 파이프라인 정비 등 실무 개발 환경의 성숙
- 에이전트 및 멀티모달 워크로드를 겨냥한 고효율 추론 하드웨어(NVIDIA Vera, OpenAI Jalapeño)와 엣지 컴퓨팅 성능 혁신
- Ollama, LiteLLM, Anthropic SDK 등 로컬 추론 프레임워크 및 개발자 도구의 데스크톱 연동 및 규격 안정화
- 휴머노이드, 자율주행 트럭, 무인 건설 장비 등 물리적 AI 배치를 뒷받침하는 대규모 투자와 하드웨어 생태계 확장

## 🤖 로보틱스 하이라이트

- **Nav2 1.3.13**: ROS 2 Jazzy와의 최신 동기화 업데이트가 릴리스되었습니다 [<a href="#ref-1">1</a>].
- **GzSensorMonitor**: Gazebo Harmonic 환경 내부에서 시뮬레이션 센서 피드백을 실시간으로 시각화하는 오픈소스 플러그인이 공개되었습니다 [<a href="#ref-2">2</a>].
- **Ros2_pulse**: Jetson AGX Orin 등에서 시스템 변경 없이 프로세스 내 통신을 포함한 토픽 전송률과 노드 활성 상태를 측정하는 도구가 공개되었습니다 [<a href="#ref-3">3</a>].
- **ROS2 Visual Servoing Controllers**: ROS 2 Jazzy 환경에서 위치 기반 및 이미지 기반 비주얼 서보잉 작업을 수행할 수 있는 제어기 패키지가 발표되었습니다 [<a href="#ref-4">4</a>].
- **Dockerized ROS 1 Noetic ↔ ROS 2 Jazzy Bridge**: Ubuntu 24.04 환경에서 대규모 레거시 ROS 1 시스템을 ROS 2로 점진적으로 이전할 수 있도록 지원하는 도커 브리지가 공개되었습니다 [<a href="#ref-5">5</a>].

## ✨ AI 도구 하이라이트

- **Ollama v0.33.0 / v0.33.1 / v0.33.2**: Claude 데스크톱 메뉴바 모델 제어, Qwen3.8-Flash-Next 지원 및 MLX 구조화 출력 기능이 추가되었습니다 [<a href="#ref-6">6</a>] [<a href="#ref-7">7</a>] [<a href="#ref-8">8</a>].
- **LiteLLM v1.98.0**: 배포 무결성과 보안 강화를 위해 cosign 기반 Docker 이미지 서명 검증을 도입했습니다 [<a href="#ref-9">9</a>].
- **Anthropic SDK v1.1.0 / v1.2.0**: Thinking 표시 모드 베타 추가 및 Organization API 지원, 베타 네임스페이스 GA 규격 전환이 반영되었습니다 [<a href="#ref-10">10</a>] [<a href="#ref-11">11</a>].
- **llm 0.33**: OpenAI Python 라이브러리 3.x 업그레이드와 함께 HTTP 클라이언트 의존성을 httpx2로 전환했습니다 [<a href="#ref-12">12</a>].
- **Qwen3.8-Flash-Next**: 125B 총 파라미터 중 6B 활성 파라미터를 사용하는 고효율 멀티모달 MoE 오픈 모델이 공개되었습니다 [<a href="#ref-13">13</a>].

## 📈 트렌드 하이라이트

- **NVIDIA Vera Rubin NVL72 및 Vera CPU 출하**: 에이전틱 워크로드에 최적화된 고속 토큰 생성 아키텍처와 전용 CPU 시스템 배포가 시작되었습니다 [<a href="#ref-14">14</a>] [<a href="#ref-15">15</a>].
- **OpenAI Jalapeño**: 기존 하드웨어 대비 전력 효율과 처리량을 개선한 OpenAI의 자체 AI 추론 전용 칩 성능 결과가 공개되었습니다 [<a href="#ref-16">16</a>] [<a href="#ref-17">17</a>].
- **XPeng Dogotix 9억 달러 투자 유치**: 휴머노이드 로봇 양산을 목표로 63억 달러의 기업 가치를 인정받으며 대규모 투자를 유치했습니다 [<a href="#ref-18">18</a>].
- **Gatik 2억 달러 투자 유치**: 물류 거점과 매장을 잇는 고빈도 간선 자율주행 트럭 운용 확장을 위해 투자를 유치했습니다 [<a href="#ref-19">19</a>].
- **NVIDIA Jetson Orin Nano 2 발표**: 엣지 로보틱스 환경에서 프론티어 AI의 실시간 추론 성능을 2배 향상시켰습니다 [<a href="#ref-20">20</a>].
