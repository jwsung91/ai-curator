## 🗓 이번 주 핵심 흐름

- ROS 2 생태계를 중심으로 제로카피 GPU 데이터 공유, GPU 가속 모션 플래닝, 실시간 지원 미들웨어 등 로봇 런타임 인프라의 가속화 및 안정성 확보가 다각도로 추진되었습니다.
- MCP 2.0 프로토콜 확산과 더불어 추론 트레이스 시각화, 로컬 추론 엔진 가속 등 에이전틱 작업 및 개발 워크플로우 자동화를 위한 도구 생태계가 고도화되었습니다.
- 피지컬 AI 파운데이션 모델과 자율주행·로보택시 솔루션의 현장 배치가 가속화되는 동시에, 제조 원가 절감 및 각국의 외산 로봇 규제 대응이 산업 상용화의 핵심 과제로 떠올랐습니다.
- 자율 행동 AI 에이전트의 개발이 본격화됨에 따라 미승인 동작에 대한 사이버 보안 평가 및 검증 가이드라인 마련을 위한 공공·민간 차원의 대응이 심화되었습니다.

## 🤖 로보틱스 하이라이트

- **ROS 2 Realtime Support Package**: 기존 패키지 수정 없이 rcl 및 rclcpp에 실시간 제어 기능을 제공하는 신규 패키지 공개 [<a href="#ref-1">1</a>]
- **Nav2 1.5.0 및 ROS 2 Lyrical 동기화 배포**: Lyrical 배포판 정기 메인 리포지토리 동기화와 함께 Nav2 1.5.0 공식 릴리스 진행 [<a href="#ref-2">2</a>, <a href="#ref-3">3</a>, <a href="#ref-4">4</a>]
- **ros2_cuda_ipc**: CPU 메모리 복사 없이 ROS 2 프로세스 간 GPU 메모리 상주 데이터를 제로카피로 공유하는 라이브러리 공개 [<a href="#ref-5">5</a>]
- **curobo_ros v2**: NVIDIA cuRobo v0.8.0 기반으로 GPU 가속 궤적 계획 성능을 높인 ROS 2 마이그레이션 라이브러리 출시 [<a href="#ref-6">6</a>]
- **Rosbag Resurrector**: DuckDB 색인 및 Pandas 아키텍처 기반으로 MCAP 로그 분석과 ML 데이터 내보내기를 지원하는 워크벤치 공개 [<a href="#ref-7">7</a>]

## ✨ AI 도구 하이라이트

- **Model Context Protocol 2.0 (Stateless MCP)**: 에이전트와 콘텍스트 간 상태 관리를 효율화하는 Stateless MCP 규격 공개 및 세션 평가 도구 확장 [<a href="#ref-8">8</a>, <a href="#ref-9">9</a>]
- **LLM CLI 0.32 및 관련 생태계 업데이트**: 추론 트레이스 시각화, 서버 사이드 툴, 개선된 프롬프트 로깅을 지원하는 CLI 도구 릴리스 [<a href="#ref-10">10</a>, <a href="#ref-11">11</a>, <a href="#ref-12">12</a>]
- **Ollama v0.32.6**: Apple GPU 환경에서 Qwen3.5 모델의 MTP 헤드 활용 가속 및 OpenAI 와이어 포맷 호환성 향상 [<a href="#ref-13">13</a>, <a href="#ref-14">14</a>]
- **Meta Muse Code / Muse Spark 1.2**: 긴 컨텍스트에 대한 자율적 도구 호출 및 에이전틱 작업 성능을 특화한 코드 생성 오픈 모델 공개 [<a href="#ref-15">15</a>]

## 📈 트렌드 하이라이트

- **Google DeepMind Gemini Robotics 2**: 로봇의 전신 제어와 복잡한 작업 추론 능력을 통합한 2세대 로보틱스 파운데이션 모델 발표 [<a href="#ref-16">16</a>, <a href="#ref-17">17</a>]
- **NVIDIA Alpamayo 2 Super 및 Omniverse 기반 Physical AI**: 자율주행 특화 오픈 모델의 상용화 및 오픈 월드 모델을 통한 피지컬 AI 생태계 확장 [<a href="#ref-18">18</a>, <a href="#ref-19">19</a>]
- **미국 FCC 규제 조치 및 외산 로봇 정책 논의**: FCC Covered List 지정에 따른 국내외 로봇 공급망 정책 변화와 물류 AI의 보안성 부각 [<a href="#ref-20">20</a>, <a href="#ref-21">21</a>]
- **HII, Path Robotics 및 GrayMatter Robotics와 9억 달러 계약**: 대규모 방산·제조 현장에 정밀 자율 작업 로봇을 도입하는 HYPER 프로그램 확대 [<a href="#ref-22">22</a>]
- **Zoox 양산형 로보택시 및 자율운항·휴머노이드 상용화**: 양산형 로보택시 디자인 공개와 Toyota-Walden 휴머노이드 파트너십 등 산업 현장 배치 본격화 [<a href="#ref-23">23</a>, <a href="#ref-24">24</a>]
