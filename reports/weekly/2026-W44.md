## 🤖 로보틱스 하이라이트

- **Gazebo Harmonic 해양 레이더 플러그인**: ROS 2 연동을 지원하며 PPI 레이더 영상, 반사 포인트 클라우드, 타깃 검출 목록의 3가지 출력을 발행합니다 [<a href="#ref-1">1</a>].
- **Robotheca 로봇 카탈로그**: 475종의 로봇에 대한 CAD/STL 파일, 부품 목록, 하드웨어·소프트웨어 라이선스, ROS 2 및 URDF 태그 정보를 제공하는 오픈 카탈로그가 공개되었습니다 [<a href="#ref-13">13</a>].
- **Webots 이중 지연 안전 게이트 아키텍처 실험**: 인지 모델이 이동 권한을 박탈할 수는 있으나 다시 인가할 수는 없도록 제한하는 결정론적 안전 규칙 실험 결과가 공유되었습니다 [<a href="#ref-2">2</a>].
- **STVL 장애물 폴리곤 기능**: 로봇 본체 등으로 인한 차폐 영역을 지정하여 센서 절두체 내부에서도 복셀이 감쇠되어 지워지지 않도록 유지하는 옵션이 추가되었습니다 [<a href="#ref-14">14</a>].
- **BTick 모니터링 도구**: 다중 트리 모니터링, 중단점 및 단계 실행, 블랙보드 변수 검사 및 수정, Nav2 로깅 시각화를 지원합니다 [<a href="#ref-15">15</a>].
- **RoboStack 모노레포 통합**: 주요 배포판 채널을 단일 리포지토리로 통합 관리하여 패치, 신규 패키지 추가, 테스트, 리빌드를 단일 PR로 적용할 수 있게 변경되었습니다 [<a href="#ref-16">16</a>].
- **ROS 2 GUI Installer**: ROS 2, Gazebo, Nav2, MoveIt 2 설치를 지원하고 워크숍 프로필 YAML을 공유할 수 있는 GTK4 기반 도구가 공개되었습니다 [<a href="#ref-17">17</a>].
- **Oculus M3000d ROS 2 드라이버**: Blueprint Subsea Oculus M3000d 이미징 소나를 위한 저수준 C++ 센서 드라이버 및 ROS 2 Jazzy 인터페이스가 공개되었습니다 [<a href="#ref-18">18</a>].
- **ROS PMC 프로젝트 리드 선임**: ROS PMC의 신임 프로젝트 리드로 Alejandro Hernández Cordero가 선정되었습니다 [<a href="#ref-19">19</a>].
- **REP 0157 rosidl 재설계 회의**: 언어 중립적 메모리 레이아웃과 XCDRv1 인메모리 표현 표준화를 통해 프로세스 간 제로카피 전송 오버헤드를 줄이기 위한 rosidl 재설계 회의가 공지되었습니다 [<a href="#ref-20">20</a>].
- **GPT-6 Astra와 ROS 2 제어 하네스 실험**: 범용 모델의 도구 호출을 ROS 2 및 ros2_control 명령어로 변환하고 카메라 영상과 상태를 피드백 루프로 반환하는 물리 로봇 및 Gazebo 구동 실험이 공유되었습니다 [<a href="#ref-3">3</a>].

## ✨ AI 도구 하이라이트

- **OpenAI GPT-6.1 Terra 발표**: 시각 추론과 컴퓨터 사용을 결합한 모델로, 100만 토큰당 입력 1달러, 출력 5달러의 가격이 책정되었습니다 [<a href="#ref-21">21</a>].
- **Moonshot AI Kimi K3.1 Pro API 출시**: 100만 토큰당 입력 2달러, 출력 10달러로 출시되었으며 전체 모델 가중치 공개 계획을 공표했습니다 [<a href="#ref-22">22</a>].
- **Google DeepMind Gemini 4 Carbon 발표**: SEC-bench Pro 88.2%, CWE-bench 71.0%를 기록한 보안 특화 모델로 100만 토큰당 입력 2달러, 출력 10달러로 출시됩니다 [<a href="#ref-23">23</a>, <a href="#ref-24">24</a>].
- **MCP 서버 v2.1.0 취약점 패치**: server-filesystem, server-everything, mcp-server-fetch 전반에서 파일시스템 탈출 등 8건의 보안 취약점을 해결했습니다 [<a href="#ref-25">25</a>].
- **MCP 서버 v2.2.0 루트 CA 갱신**: eMudhra 중간 CA 유출에 대응하여 certifi 패키지 업데이트를 반영하고 Node.js 보안 권장 버전을 안내했습니다 [<a href="#ref-26">26</a>].
- **Ollama v0.40.11~v0.40.13**: macOS 상의 음성 생성 API 지원을 추가하고, Liquid AI의 LFM3 멀티모달 모델 제품군 및 텍스트 음성 변환 지원을 Linux와 Windows로 확장했습니다 [<a href="#ref-4">4</a>, <a href="#ref-7">7</a>, <a href="#ref-8">8</a>].
- **LiteLLM v1.106.4~v1.106.6**: 원격 모델 비용 맵 미접속 시 발생하는 ImportError 수정, 거부된 요청에 대한 실패 로그 필드 정제, gzip 압축 백포트가 적용되었습니다 [<a href="#ref-27">27</a>, <a href="#ref-28">28</a>, <a href="#ref-29">29</a>].
- **Hob 로컬 LLM 앱**: Mac, Windows, Linux 환경에서 오픈 가중치 모델을 로컬로 구동할 수 있는 오프라인 오픈소스 데스크톱 앱이 공개되었습니다 [<a href="#ref-5">5</a>].
- **Survival LLM 지식 도구**: 응급 처치 및 생존 안내를 로컬 컴퓨터에서 오프라인으로 검색하고 출처 문서를 직접 표시하는 도구가 공개되었습니다 [<a href="#ref-6">6</a>].
- **Webframe 스크레이퍼**: Go 기반으로 glaze 라이브러리를 사용해 시스템 내장 브라우저 환경에서 웹 페이지를 헤드리스로 실행하고 표준 출력을 콘솔로 내보내는 도구 평가가 공유되었습니다 [<a href="#ref-30">30</a>].
- **Anthropic Python SDK v2.3.0**: Claude Enterprise 조직을 위한 Claude Tag 엔드포인트가 추가되었습니다 [<a href="#ref-31">31</a>].

- **Eka Robotics 1억 5,000만 달러 시리즈 A 유치**: 대규모 강화학습 기반의 조작용 Vision-Force-Action 모델 확장을 위해 1억 5,000만 달러 규모의 펀딩을 확보했습니다 [<a href="#ref-34">34</a>].
- **Warp Sciences 2억 1,500만 달러 유치**: 화학, 로보틱스, AI를 결합한 분자 제작 및 신약 발굴 자동화 인프라 구축을 위해 2억 1,500만 달러를 유치했습니다 [<a href="#ref-35">35</a>].
- **OMRON의 OnLogic 인수 합의**: 엣지 산업 자동화 역량 강화를 위해 산업용 컴퓨팅 기업 OnLogic 지분 100%를 6억 7,500만 달러에 인수하기로 합의했습니다 [<a href="#ref-11">11</a>].
- **Teradyne Robotics와 Sereact 협력**: Sereact Cortex AI와 Universal Robots 듀얼 암 시스템을 결합하여 유럽 물류 현장에 반품 의류 처리 자동화 시스템을 공급했습니다 [<a href="#ref-9">9</a>].
- **Agility Robotics와 GXO 파트너십 확장**: 노스캐롤라이나와 테네시 물류 거점에 Digit 휴머노이드 로봇을 추가 배치하기로 합의했습니다 [<a href="#ref-12">12</a>].
- **BMW와 Embotech 공장 내 차량 이동 실적**: 인프라 기반 레벨 4 자율주행 기술을 통해 영국 및 독일 4개 공장에서 100만 대의 완성차 이동을 기록했습니다 [<a href="#ref-36">36</a>].
- **ANYbotics ANYmal X 납품 개시**: 가연성 위험 환경 작업을 위한 ATEX 및 IECEx 방폭 인증 4족 보행 로봇의 상용 공급을 시작했습니다 [<a href="#ref-37">37</a>].
- **Xpanner 자율 항타 로봇 X1 Piling R6 발표**: 고정밀 GNSS와 자체 컨트롤러를 탑재하여 태양광 및 에너지 저장 시설에 말뚝을 자율 설치하는 건설 로봇을 발표했습니다 [<a href="#ref-38">38</a>].
- **AGIBOT 생산성 측정 지표 및 로봇 발표**: 실환경 작업 생산성을 평가하는 프레임워크 Worken과 고하중 로봇 G2 Max를 제안했습니다 [<a href="#ref-39">39</a>].
- **Luxonis OAK 4 FFC 발표**: 최대 5개 카메라를 연동해 동기화, 깊이, AI 연산을 처리하는 70mm x 53mm 규격의 소형 비전 컴퓨터를 공개했습니다 [<a href="#ref-40">40</a>].
