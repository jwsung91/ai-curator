## 🤖 로보틱스 하이라이트

- **ROS 2 Humble 패키지 업데이트 동기화 (humble/2026-10-12)**: ROS 2 Humble Hawksbill에 40개의 신규 패키지가 추가되고 446개 패키지 업데이트가 반영된 동기화 태그가 발표되었습니다 [<a href="#ref-9">9</a>].
- **Rokoko Device SDK 업데이트**: 비정상 종료 시 USB 데이터 스트림을 안정화하고 펌웨어 성능 개선 및 차기 릴리스를 위한 Wi-Fi OTA 준비와 핀치 제스처 감지 예제를 추가했습니다 [<a href="#ref-10">10</a>].
- **DendROS**: ros2 커맨드를 래핑하여 노드 그룹별 터미널 색상을 지정하고 실행 중 로그 스크롤, 검색, 필터링이 가능한 인터랙티브 뷰어를 제공합니다 [<a href="#ref-11">11</a>].
- **rclnodejs 2.3.0**: Node.js 클라이언트 환경에서 WebSocket 및 HTTP/SSE를 통해 웹 애플리케이션으로 ROS 2 액션 목표 전송, 피드백 수신, 결과 조회를 지원합니다 [<a href="#ref-12">12</a>].
- **PlanSys2 새 기본 플래너 Kairos 및 STN 기반 실행기 도입**: ROS 종속성이 없는 C++ 라이브러리 형태의 Kairos 플래너를 새 기본 플래너로 채택하고 시간 제약 병렬 실행을 위한 STNBTBuilder를 실행기로 도입했습니다 [<a href="#ref-13">13</a>].
- **VizMini2**: 안드로이드 기기가 별도 rosbridge 없이 동일 네트워크의 DDS 참여자로 동작하여 Fast DDS 기반 노드와 직접 통신하며 3D 시각화 및 원격 제어를 제공합니다 [<a href="#ref-14">14</a>].
- **RoboShield v2**: Rust rclrs 기반으로 2개의 도메인 ID 컨텍스트를 중계하는 인라인 게이트웨이로 동작하며, 규칙 엔진을 통해 비정상 관절 명령을 필터링하고 이상 감지 시 자동 록다운을 수행합니다 [<a href="#ref-15">15</a>].
- **RobotLens**: Vulkan 렌더링 기반 3D 시각화, ROS 2 및 Zenoh 토픽 검사, Gazebo 및 MuJoCo 시뮬레이션, 디버깅 워크플로를 하나의 인터랙티브 엔지니어링 작업 공간으로 통합했습니다 [<a href="#ref-16">16</a>].
- **Gemini 4 Argon 로보틱스 활용 사례**: MuJoCo 물리 시뮬레이션 연습을 통한 Boston Dynamics Spot 로봇의 모바일 매니퓰레이션 조작 학습 및 비디오 기반 Real2Sim 환경 복원 사례를 제시했습니다 [<a href="#ref-2">2</a>].
- **ros2_pulse 0.6.0**: rmw_take 트레이스포인트를 후킹하여 rclpy 수신을 계측하고 Fast DDS 기본 대여 메시지 주파수 모니터링 및 Prometheus/Grafana 연동을 지원합니다 [<a href="#ref-17">17</a>].
- **DDS Monitor Pro MCP 통합 프리뷰**: 내장 MCP 서버를 통해 호환 AI 어시스턴트가 DDS 계층의 엔티티, 토픽, 신뢰성 QoS 구성을 직접 조사하고 통신 문제를 진단할 수 있도록 지원합니다 [<a href="#ref-6">6</a>].

## ✨ AI 도구 하이라이트

- **Python 3.15**: PEP 810 명시적 지연 임포트(lazy import) 문법과 저오버헤드 표준 샘플링 프로파일러인 Tachyon(profiling.sampling)을 내장했습니다 [<a href="#ref-18">18</a>].
- **Janas-LLM**: C 언어로 구현되어 NVMe SSD에서 필요한 전문가 가중치를 O_DIRECT로 스트리밍함으로써 32GB RAM 노트북 등 일반 PC 환경에서 Qwen3-Next-80B 모델 추론을 지원합니다 [<a href="#ref-19">19</a>].
- **Anthropic Python SDK 업데이트 (v1.13.0 ~ v1.15.0)**: Managed Agents 멀티에이전트 구성과 OpenTelemetry 기반 추적 기능을 추가하고 thinking 타입에 between_tools 및 Messages API 속도 파라미터를 지원합니다 [<a href="#ref-20">20</a>, <a href="#ref-21">21</a>, <a href="#ref-22">22</a>].
- **공식 MCP 서버 패키지 v1.0.0**: modelcontextprotocol 레포지토리의 server-everything, server-filesystem, server-memory, server-sequential-thinking 패키지가 npm에 1.0.0 정식 버전으로 배포되었습니다 [<a href="#ref-4">4</a>].
- **Ollama 업데이트 (v0.40.3 ~ v0.40.5)**: 터미널에서 질의 및 분류를 수행하는 의사결정 모델 CLI 지원을 추가하고 하이브리드 구조의 Nemotron 3.5 Super 및 Bolt 모델 구동을 지원합니다 [<a href="#ref-23">23</a>, <a href="#ref-24">24</a>, <a href="#ref-7">7</a>].
- **LiteLLM 업데이트 (v1.105.0 ~ v1.105.1)**: 도구 표면 전반의 호환 MCP 결과 변환 및 프로토콜 버전 설정을 추가하고 프록시 관련 백포트 패치를 적용했습니다 [<a href="#ref-5">5</a>, <a href="#ref-25">25</a>].
- **Google DeepMind Gemini 4 Argon**: 코딩 벤치마크 편법 시도율을 2%로 낮추고 실시간 미스얼라인먼트 모니터를 적용했으며, AI Studio 및 API를 통해 100만 토큰당 입력 2달러·출력 10달러 요금으로 출시되었습니다 [<a href="#ref-1">1</a>, <a href="#ref-3">3</a>].
- **Anthropic Scion**: 메인 브랜치 100GB 및 일일 약 2,500만 건 CI 체크아웃 부하를 해결하기 위해 사내 버전 관리 시스템 Scion을 구축하고 5개월 만에 모노레포를 Git에서 마이그레이션했습니다 [<a href="#ref-26">26</a>, <a href="#ref-27">27</a>].
- **Spool**: 독립된 격리 컨테이너 환경에서 Claude Code 루프를 지속 실행하고 세션 재개 및 채팅 기반 모니터링을 오케스트레이션합니다 [<a href="#ref-28">28</a>].
- **NVIDIA Nemotron 3.5 Super VL 및 Bolt 74B-A9B**: 120B 파라미터 규모의 멀티모달 오픈 모델 Nemotron 3.5 Super VL과 24GB 메모리 환경에 맞춘 Bolt 74B-A9B 가중치를 공개했습니다 [<a href="#ref-8">8</a>].

- **NVIDIA의 영국 스타트업 투자**: Boltz, Foresight, Hiverge, Prima Mente, Riverlane 등 영국의 AI 및 양자 컴퓨팅 스타트업 5곳에 대한 신규 투자 계획을 발표했습니다 [<a href="#ref-32">32</a>].

- **Stryker-CMR Surgical 투자 계약**: Stryker가 CMR Surgical에 약 4억 달러를 투자하여 미국 내 Versius 로봇 독점 판매권과 잔여 지분 독점 인수 옵션을 확보했습니다 [<a href="#ref-34">34</a>].
- **Agility Robotics-Nyobolt 파트너십**: Digit 5 휴머노이드 로봇에 9분 완충으로 90분 구동 가능한 급속 충전 배터리 시스템을 적용하기 위해 Nyobolt와 협력합니다 [<a href="#ref-35">35</a>].
