## 🤖 로보틱스 하이라이트

- **RobotCAD v12.10.0**: 에이전트 기반 로봇 조립을 지원하는 MCP 서버가 추가되고 Gazebo에서 ROS 2로 센서 데이터를 전달하는 브리지 기능이 도입되었습니다 [<a href="#ref-4">4</a>].
- **ROS Lyrical 패키지 동기화**: ROS Lyrical 배포판에 29개의 신규 패키지와 265개의 패키지 업데이트가 적용되었습니다 [<a href="#ref-5">5</a>].
- **DialoStack**: 제어 흐름을 파이썬 상태 머신(FSM)으로 처리하고 LLM은 사용자 입력 해석과 응답 생성에만 제한적으로 활용하는 ROS 2 대화 프레임워크가 공개되었습니다 [<a href="#ref-6">6</a>].
- **ROS 2 Jazzy Jalisco 패키지 동기화**: ROS 2 Jazzy Jalisco 배포판에 190개의 신규 패키지와 312개의 업데이트 패키지가 동기화되었습니다 [<a href="#ref-7">7</a>].
- **Robot Brain 알파**: 로봇의 작업 경험을 사실 출처와 함께 보존하고 다음 작업 시 관련 메모리를 로컬 HTTP API 및 ROS 2 참조 브리지로 제공하는 런타임이 공개되었습니다 [<a href="#ref-8">8</a>].
- **Hold_and_weld v0.3.0**: CAD 형상 기반 용접선 추출과 파지 샘플링을 결합해 고정 지그 없이 두 로봇 암이 협업하도록 설계된 오픈소스 프레임워크가 공개되었습니다 [<a href="#ref-9">9</a>].
- **Pegasus 1.6**: 1인칭 작업 영상의 동작을 시간 단위로 분할하고 레이블을 생성해 로봇 정책 훈련 데이터 구축을 지원하는 비디오 이해 모델이 발표되었습니다 [<a href="#ref-10">10</a>].
- **Rokoko Smartgloves II ROS 2 브리지**: Smartgloves II의 손 데이터를 ROS 2 환경에 네이티브로 수신할 수 있는 Apache 2.0 라이선스 기반 드라이버가 출시되었습니다 [<a href="#ref-11">11</a>].
- **HiPHI 데이터셋**: 밀리미터 이하 정밀도로 수집된 617.5시간 분량의 전신 모션 캡처 데이터와 동기화된 물체 궤적을 포함하는 벤치마크가 공개되었습니다 [<a href="#ref-12">12</a>].
- **ros2_control 6.12.0 레거시 API 제거 예고**: Jazzy 이후 비권장 처리되었던 원시 포인터 핸들과 값 반환형 export 메서드가 Rolling 및 Lyrical에서 제거되었으며 다음 동기화 시 적용될 예정입니다 [<a href="#ref-13">13</a>].
- **Uranus**: 관절 궤적 조건부 자기회귀 확산 월드 모델을 통해 미래 다중 시점 프레임을 생성하고 폐루프 시뮬레이션을 제공하는 데이터 기반 로봇 시뮬레이션 모델이 공개되었습니다 [<a href="#ref-14">14</a>].
- **Kyvern**: 로봇 제어기의 결정 규칙과 입력 데이터를 서명된 해시 체인으로 기록하고 외부에서 검증할 수 있도록 지원하는 Apache 2.0 라이선스 파이썬 라이브러리가 발표되었습니다 [<a href="#ref-15">15</a>].
- **손가락 보행·조작 로봇 핸드 연구**: 상용 로봇 핸드를 활용해 손가락 끝으로 이동하면서 동일한 손가락으로 물체를 조작하는 자립형 시스템 연구가 발표되었습니다 [<a href="#ref-16">16</a>].
- **AI 에이전트 기반 Omniverse 시뮬레이션 워크플로**: 개발자들이 프론티어 AI 모델과 Omniverse 물리 및 렌더링 라이브러리를 결합해 시뮬레이터와 센서 디지털 트윈을 구축하는 워크플로가 소개되었습니다 [<a href="#ref-17">17</a>].

## ✨ AI 도구 하이라이트

- **Ollama v0.35.1**: /v1/systemone 엔드포인트를 통해 Cloudflare의 Clef 및 Clef Flash 판정 모델을 지원합니다 [<a href="#ref-18">18</a>].
- **LiteLLM v1.104.0**: 모든 도커 이미지에 cosign 기반 암호화 서명이 적용되었으며 마스터 키 보안 검증 절차가 강화되었습니다 [<a href="#ref-19">19</a>].
- **NVIDIA DGX Spark 64GB**: 64GB 통합 메모리를 탑재한 시스템이 파트너 제조사를 통해 공급되며 2대 연결 시 128GB로 확장이 가능합니다 [<a href="#ref-1">1</a>].
- **OpenAI 수학 난제 연구 및 Lean 코드 공개**: 내부 프론티어 모델을 활용한 수학 오픈 프라블럼 연구 결과와 함께 Lean 기계 증명 형식화 코드가 GitHub에 공개되었습니다 [<a href="#ref-20">20</a>].
- **EmbeddingGemma 2**: Gemma 4 아키텍처 기반의 740M 파라미터 경량 멀티모달 임베딩 모델로, MRL 기법을 통해 출력 벡터 차원을 최대 128차원까지 동적 축소할 수 있습니다 [<a href="#ref-21">21</a>, <a href="#ref-22">22</a>].
- **Mistral Large 4 API 프리뷰**: 1조 파라미터(활성 파라미터 490억 개) 규모의 추론 모델 프리뷰가 API로 공개되었으며 추론 단계를 none과 high로 제공합니다 [<a href="#ref-23">23</a>].
- **Ollama v0.40.0**: Apple Silicon 환경에서 지원되는 모델 아키텍처 실행 시 기본 런타임이 MLX로 자동 전환됩니다 [<a href="#ref-24">24</a>].
- **OpenAI GPT-6 전면 배포 (피드 요약 기반)**: 시각 및 상호작용 인터페이스인 Intelligent UI를 결합한 GPT-6가 ChatGPT에 글로벌 배포되기 시작했습니다 [<a href="#ref-25">25</a>].
- **Claude Haiku 5.5**: 10만 토큰 이하 요청에 대해 입력 100만 토큰당 0.10달러, 출력 0.50달러로 출시되었으며, Claude Sonnet 5.5의 캐시 읽기 단가는 50% 인하되었습니다 [<a href="#ref-26">26</a>, <a href="#ref-27">27</a>].
- **Anthropic 파이썬 SDK v1.12.0**: claude-haiku-5-5 지원과 함께 타입화된 컴퓨터 및 브라우저 도구 호출 기능이 추가되었습니다 [<a href="#ref-28">28</a>].
- **Windows RTX Spark 및 MXC**: Windows에서 에이전트를 백그라운드에서 실행할 수 있는 OS 레벨 인프라 Microsoft Execution Containers(MXC)와 RTX Spark 시스템이 발표되었습니다 [<a href="#ref-3">3</a>].
- **LiteLLM v1.104.2**: /v1/systemone 및 OpenAI 규격의 Decisions API 연동 기능이 stable/1.104.x 브랜치로 백포트되었습니다 [<a href="#ref-29">29</a>].

- **Boston Dynamics 신임 CEO 선임**: 전 아마존 부사장 겸 수석 과학자 Rohit Prasad가 신임 CEO로 임명되었습니다 [<a href="#ref-32">32</a>].

- **Meta와 Microsoft의 사내 외부 AI 사용 축소**: 양사가 사내 비용 절감과 자체 도구 전환을 위해 엔지니어의 Claude AI 사용량과 한도를 감축했습니다 [<a href="#ref-34">34</a>].
- **Schneider Electric의 PTC 인수**: Schneider Electric이 산업 설계 및 PLM 기업 PTC를 약 226억 달러에 인수하기로 합의했습니다 [<a href="#ref-35">35</a>].
- **Teradyne Robotics와 Elite Robots 분쟁 종결**: 협동로봇 및 소프트웨어와 관련된 양사 간의 법적 분쟁이 상호 합의로 공식 종결되었습니다 [<a href="#ref-36">36</a>].
- **SafeWorld 시드 투자 유치**: AI 로봇 안전 검증 시뮬레이션 플랫폼을 개발하는 SafeWorld가 1,220만 달러 규모의 시드 투자를 유치했습니다 [<a href="#ref-37">37</a>].
- **Helm.ai 피지컬 AI 상업 계약**: Helm.ai가 지난 12개월 동안 피지컬 AI 파운데이션 모델과 관련해 7,000만 달러 규모의 상업 계약을 체결했다고 발표했습니다 [<a href="#ref-38">38</a>].
