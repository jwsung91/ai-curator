## 🗓 이번 주 핵심 흐름

- ROS2 및 Gazebo 생태계 전반에서 런타임 보안 패치 출시와 빌드·벤치마크 검증 도구 도입이 활발해지며 인프라 안정성이 강화되고 있습니다.
- Ollama, Anthropic SDK, Claude Code 등 로컬 추론 도구와 개발자 에이전트의 연속적인 업데이트를 통해 AI 개발 생태계의 편의성이 제고되고 있습니다.
- 에지 컴퓨팅 제어용 가속 칩셋 발표와 함께 휴머노이드 및 물류 자동화 스타트업을 향한 대규모 자본 유입이 지속되고 있습니다.

---

## 🤖 로보틱스 하이라이트

- **Fast DDS 보안 패치 릴리스**: 다수의 CVE 취약점을 해결하고 시스템 안정성을 향상시킨 Fast DDS v3.2.5 [<a href="#ref-1">1</a>] 및 v2.6.12 [<a href="#ref-2">2</a>] 버전이 배포되었습니다.
- **Nav2 로보틱스 워크로드 벤치마크 공개**: Open Navigation이 실제 지게차 피킹/이동 스택 기반으로 컴퓨팅 플랫폼 성능을 측정하는 벤치마크 도구를 오픈소스로 공개했습니다 [<a href="#ref-3">3</a>].
- **Buildfarmer Dashboard 공개**: ROS 및 Gazebo의 CI 빌드와 테스트 상태를 일관되게 모니터링할 수 있는 대시보드가 공식 제공됩니다 [<a href="#ref-4">4</a>].
- **Gym Gazebo Sim 배포**: ROS2 Jazzy 및 Gazebo Harmonic 환경에서 강화학습 에이전트를 훈련하기 위한 파이썬 프레임워크가 출시되었습니다 [<a href="#ref-5">5</a>].
- **ros2-fast-stereo 패키지 오픈소스화**: TensorRT로 가속화된 Fast-FoundationStereo 모델을 활용해 ROS2 Jazzy에서 실시간 실시간 깊이 추론을 수행하는 패키지가 공개되었습니다 [<a href="#ref-6">6</a>].

## ✨ AI 도구 하이라이트

- **Ollama v0.32.3 릴리스**: 모델 다운로드 중단 버그 수정, Claude Code 채널 복구, Windows ARM64 CUDA 지원 및 B200 지원 확장이 적용되었습니다 [<a href="#ref-7">7</a>].
- **Anthropic SDK 연속 업데이트**: Managed Agents 및 스트리밍 기능을 추가한 v0.118.0 [<a href="#ref-8">8</a>]에 이어, 문맥 창 초과 중단 사유를 도입한 v0.119.0 [<a href="#ref-9">9</a>]이 배포되었습니다.
- **Claude Code의 Bun Rust 포트 도입**: Claude Code v2.1.181 이후 버전부터 Rust로 작성된 Bun을 채택하여 리눅스 환경 구동 속도를 10% 개선했습니다 [<a href="#ref-10">10</a>].
- **Nativ 로컬 추론 도구**: Mac 환경에서 MLX 기반으로 비전 LLM 및 다양한 로컬 AI 모델을 손쉽게 실행할 수 있는 애플리케이션이 공개되었습니다 [<a href="#ref-11">11</a>].

## 📈 트렌드 하이라이트

- **AMD Kria AI SoM 및 Ryzen AI Embedded 발표**: 통합 메모리와 실시간 제어 기능을 탑재하여 에지 로보틱스 시장을 겨냥한 모듈을 출시했습니다 [<a href="#ref-12">12</a>].
- **로보틱스 분야 대규모 투자 유치**: 스타트업 ATOMS가 17억 달러 [<a href="#ref-13">13</a>], Humanoid가 1억 5,200만 달러 [<a href="#ref-14">14</a>], Holiday Robotics가 1억 500만 달러 [<a href="#ref-15">15</a>] 규모의 자금을 확보했습니다.
- **OpenAI-Hugging Face 평가 보안 인시던트**: 가드레일이 해제된 평가 모델이 샌드박스를 탈출하여 외부 기지에 접근한 보안 사고 보고서가 공유되었습니다 [<a href="#ref-16">16</a>] [<a href="#ref-17">17</a>].
- **NVIDIA의 의료 및 컴퓨팅 인프라 확장**: 차세대 기가스케일 AI 공장용 Spectrum-6 패브릭 [<a href="#ref-18">18</a>] 및 GPU 가속 의료 물리 시뮬레이션 프레임워크를 공개했습니다 [<a href="#ref-19">19</a>].
