- 해석: 물리 로봇 제어 분야에서 비디오 기반 파운데이션 모델 및 월드 모델 가상 합성 데이터를 활용해 범용 작업 적응성을 높이려는 파이프라인 개발이 구체화되고 있습니다 [<a href="#ref-1">1</a>, <a href="#ref-2">2</a>].

---

## 🤖 로보틱스 하이라이트

- **Swift-ros2 3.0**: 별도의 브리지나 rcl 크로스 컴파일 없이 Zenoh 또는 DDS를 통해 Swift 앱이 ROS 2 그래프에 직접 참여하도록 지원하며, swift-ros2-rosidl 등 세 패키지로 분리되어 독립 GitHub 조직으로 이전되었습니다 [<a href="#ref-3">3</a>].
- **robot-data-diff**: LeRobot 데이터셋의 두 리비전을 비교하여 에피소드 변경 내역과 액션 통계 및 유휴 비율을 HTML 리포트로 출력하는 도구로, 비디오 다운로드 없이 CPU만으로 동작합니다 [<a href="#ref-4">4</a>].
- **NVIDIA Cosmos**: 자율주행 및 결함 이미지 생성 등 5가지 클라우드 네이티브 블루프린트를 Data Factory에 추가하고, 시뮬레이션 환경에서 자율주행 정책과 양팔 로봇 제어를 검증하는 Cosmos 3 Nano 모델 변형을 제공합니다 [<a href="#ref-2">2</a>].

---

## ✨ AI 도구 하이라이트

- **DeepInfer**: DeepSeek-V4.1-Flash 모델을 지원하는 오픈소스 추론 프레임워크로, NVIDIA SM100 GPU 및 Huawei Ascend 950 NPU 지원과 함께 FlashMLA, DeepGEMM, DeepEP 커널 및 비동기 스케줄링을 Apache 2.0 라이선스로 제공합니다 [<a href="#ref-5">5</a>].
- **DeepSeek Search 및 Fetch API**: 구조화된 웹 검색 결과와 단일 웹페이지 마크다운 추출을 제공하는 API로, 토큰 수가 아닌 성공한 요청 1,000건당 0.75달러로 과금됩니다 [<a href="#ref-6">6</a>].
- **Recursive Flint**: Apache 2.0 라이선스의 40B MoE 모델(토큰당 약 2.5B 활성화)로 262K 컨텍스트를 지원하며, RTX Spark, DGX Spark, GeForce RTX 등 로컬 하드웨어 실행에 최적화되었습니다 [<a href="#ref-7">7</a>, <a href="#ref-8">8</a>].
- **MCP Servers v2.0.0**: 레거시 클라이언트 호환성을 유지하면서 modern era 스펙을 지원하도록 공식 서버 구조를 리팩터링하였으며, TypeScript 기반 서버의 Node.js 요구 사양을 Node 24로 상향했습니다 [<a href="#ref-9">9</a>].
- **Anthropic Agent Skills**: 벤더 중립성을 확보하기 위해 Agent Skills 표준을 리눅스 재단 산하 Agentic AI Foundation(AAIF)에 기증했습니다 [<a href="#ref-10">10</a>].
- **LiteLLM 1.107.0 PyPI 공급망 침해**: PyPI에 등록되었던 1.107.0 휠 파일에 자격증명 탈취기(cook.py)와 원격 코드 실행 백도어(sitecustomize.py)가 포함되어 제거되었으며, 업스트림 소스와 1.106.2 및 RC 버전은 영향을 받지 않았습니다 [<a href="#ref-11">11</a>].

## 📈 트렌드 하이라이트

- **Agility Robotics Digit 5**: 23kg 빈을 들어 올릴 수 있고 9분 충전으로 90분 구동 가능한 배터리를 갖추도록 설계된 Digit 5를 공개했으며, AGCO의 캔자스주 헤스턴 공장에 2027년부터 투입하는 상용 파일럿 계약을 체결했습니다 [<a href="#ref-12">12</a>, <a href="#ref-13">13</a>].
- **Dream Labs**: 9,000만 달러 규모의 시드 투자를 유치하고 카메라 영상과 자연어 명령을 모터 제어로 변환하는 Dream API를 출시했으며, 주력 모델인 Dream-1은 그리퍼가 달린 양팔 로봇에 대해 제로샷 학습을 지원합니다 [<a href="#ref-1">1</a>].
- **Kodama Systems**: 산림 및 임업 장비 자율화를 위해 700만 달러를 추가 유치했으며, 원격 조작과 감독형 자율성을 결합해 상용 벌목 현장의 스키더 장비에 적용하고 있습니다 [<a href="#ref-14">14</a>].
- **OpenAI의 Orchestra Bio 인수**: 생명과학 R&D 분야에 AI 기반 운영을 도입하고 신약 개발을 가속하기 위해 Orchestra Bio 인수를 발표했습니다 [<a href="#ref-15">15</a>].
- **OpenAI-Google Cloud 파트너십**: OpenAI의 프론티어 모델과 Codex 워크플로를 Google Cloud Marketplace 및 모델 가든을 통해 배포하기로 협력했습니다 [<a href="#ref-16">16</a>, <a href="#ref-17">17</a>].
