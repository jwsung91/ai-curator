## 🗓 이번 주 핵심 흐름

- ROS 2 핵심 프레임워크 및 Gazebo 시뮬레이션 환경의 공식 업데이트와 물리 연산 패치가 잇따라 배포되었습니다.
- Meta의 Muse Glimmer와 NVIDIA Nemotron 등 로컬 환경 및 에이전트 제어에 최적화된 경량·오픈 가중치 모델 공개가 집중되었습니다.
- Ollama와 SDK 등 로컬 추론 런타임 도구들이 양자화 가속과 비동기 처리를 개선하며 실시간 AI 제어 인프라를 확장했습니다.
- 프라이빗 LLM API의 추론 트레이스 탈취 취약점과 시뮬레이션 기반 로봇 사이버 보안 검증 체계 등 AI 안전성 이슈가 부각되었습니다.

## 🤖 로보틱스 하이라이트

- **Nav2 1.5.1**: ROS 2 자율주행 내비게이션 스택의 Lyrical 신규 버전 릴리스 [<a href="#ref-1">1</a>]
- **MoveIt2 2.15.0**: 로봇 모션 플래닝 및 매니퓰레이션을 위한 공식 2.15.0 버전 업데이트 [<a href="#ref-2">2</a>]
- **Gazebo gz-sim9 9.6.0**: Gazebo 시뮬레이터 차기 버전 릴리스 준비 및 변경사항 반영 [<a href="#ref-3">3</a>]
- **AdvancedLiftDrag 물리 연산 버그 수정**: Gazebo 시뮬레이터의 AdvancedLiftDrag 시스템 내 피칭 모멘트 계산 오류 해결 [<a href="#ref-4">4</a>]
- **mppi_controller_cuda**: ROS 1과 ROS 2를 지원하는 CUDA 가속 기반 MPPI 로컬 플래너 공개 [<a href="#ref-5">5</a>]

## ✨ AI 도구 하이라이트

- **Ollama v0.32.10**: MLX NVFP4 프리필 속도 개선 및 repeat_penalty 기본값 조정을 통한 추론 최적화 [<a href="#ref-6">6</a>]
- **OpenAI API Ultrafast 모드**: Cerebras 인프라를 활용해 GPT-5.6 Sol 추론 속도를 최대 14배 가속하는 API 티어 발표 [<a href="#ref-7">7</a>]
- **Muse Glimmer**: Apache 2.0 라이선스 기반으로 로컬 에이전트 워크플로우에 활용 가능한 30B 오픈 가중치 모델 [<a href="#ref-8">8</a>]
- **Anthropic SDK v0.122.0**: 메모리 스토어 동작 제어 옵션 추가 및 AWS Bedrock SigV4 비동기 서명 버그 수정 [<a href="#ref-9">9</a>]
- **LiteLLM v1.96.2**: Cosign 기반 암호화 이미지 서명 검증을 지원하는 프록시 도구 업데이트 [<a href="#ref-10">10</a>]

## 📈 트렌드 하이라이트

- **Cambridge Aerospace 300M 달러 투자 유치**: 방산 드론 개발 역량 확대를 위한 3억 달러 규모 자금 조달 성공 [<a href="#ref-11">11</a>]
- **NVIDIA Nemotron 3.5 Lightning 발표**: 상시 구동형 에이전트 실행에 최적화된 30B MoE 오픈 모델 공개 [<a href="#ref-12">12</a>]
- **VicOne의 NVIDIA Isaac Sim 보안 확장 도구 출시**: DEF CON 34 연구를 바탕으로 로봇 배포 전 사이버 안전성을 검증하는 무료 확장 기능 제공 [<a href="#ref-13">13</a>]
- **Tate의 Hirebotics 용접 협동로봇 대규모 도입**: 생산 현장 다수 시설에 클라우드 연동 코봇 용접기 58대 구축 [<a href="#ref-14">14</a>]
- **PlusAI 자율주행 트럭 상용화 마일스톤 달성**: SuperDrive 시스템의 안전 검증과 운영 완성도를 강화하며 자율 물류 배치 준비 [<a href="#ref-15">15</a>]
