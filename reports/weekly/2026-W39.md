## 🗓 이번 주 핵심 흐름

- Isaac ROS 5.0과 rclrs 릴리스 등 에이전틱 워크플로우와 안전성을 강화한 로봇 미들웨어의 고도화가 본격화되었습니다.
- 차세대 프론티어 파운데이션 모델 공개에 발맞추어 로컬 추론 런타임과 도구 연동 인터페이스의 동반 업데이트가 가속화되었습니다.
- 시뮬레이션 기반 안전성 검증 기술과 실제 제조 및 산업 현장 중심의 하드웨어 스케일업 도입 흐름이 맞물리며 신뢰성 확보가 가속화되었습니다.

## 🤖 로보틱스 하이라이트

- **Isaac ROS 5.0 및 NITROS 5.0.0**: 에이전틱 워크플로우 지원과 GPU 가속 기반 충돌 인지 모션 플래닝 cuMotion을 도입한 신규 릴리스 배포 [<a href="#ref-1">1</a>][<a href="#ref-2">2</a>][<a href="#ref-3">3</a>]
- **rclrs 0.8.0**: ROSCon Global 2026 일정에 맞춰 안전한 Rust 기반 ROS 2 클라이언트 라이브러리 정식 업데이트 [<a href="#ref-4">4</a>]
- **ros2_unbag**: ROS 2 공식 빌드팜을 통해 정식 패키지로 제공되어 데이터 추출 파이프라인 편의성 강화 [<a href="#ref-5">5</a>]
- **ROS2 launch 3.8.9**: 런타임 실행 및 노드 관리 시스템 유지보수를 위한 신규 버전 릴리스 [<a href="#ref-6">6</a>]
- **QERRA-v2 Classical**: Webots 시뮬레이션 환경에서 로봇 동작의 안전성 보장을 위한 물리 반사 레이어 및 Behavior Tree 실행 가드 검증 [<a href="#ref-7">7</a>][<a href="#ref-8">8</a>]

## ✨ AI 도구 하이라이트

- **Anthropic SDK v1.8.0**: 신규 Claude Opus 5.5 지원 및 인라인 도구 정의, MCP 도구 목록 고정(beta) 기능 추가 [<a href="#ref-9">9</a>]
- **Ollama v0.34.4**: 씽킹 모델 대상 단일 패스 구조화 출력 적용과 대규모 라이브러리 환경의 모델 검색 오류 수정 [<a href="#ref-10">10</a>][<a href="#ref-11">11</a>]
- **LiteLLM v1.102.1**: 코사인(cosign) 기반 도커 이미지 서명 검증을 정식 지원하는 게이트웨이 업데이트 [<a href="#ref-12">12</a>][<a href="#ref-13">13</a>]
- **llm 0.36**: GPT-6 Sol 및 Luna 모델 지원을 포함한 오픈소스 CLI 도구 업데이트 [<a href="#ref-14">14</a>]

## 📈 트렌드 하이라이트

- **PickNik Inc.와 Qualcomm 파트너십**: MoveIt 개발사 PickNik과 퀄컴의 제휴를 통한 차세대 로보틱스 모션 제어 협력 추진 [<a href="#ref-15">15</a>]
- **Boston Dynamics 메타플랜트 애플리케이션 센터 개소**: 현대차 조지아 메타플랜트 아메리카와 연계하여 아틀라스(Atlas) 휴머노이드 현장 훈련 착수 [<a href="#ref-16">16</a>]
- **IFR 글로벌 산업용 로봇 통계 발표**: 전 세계 공장에 500만 대 이상의 산업용 로봇이 배치되었으며 중국, 미국, 독일 중심 시장 성장 확인 [<a href="#ref-17">17</a>]
- **Epson AX6 코봇 발표**: 경량 디자인과 노코드 프로그래밍을 지원하는 신규 6축 협동로봇 라인업 출시 [<a href="#ref-18">18</a>]
- **Hirebotics 협동로봇 기능 확장**: 리니어 레일 및 라인 트래킹 기능 도입을 통한 제조 공정 가용 작업 반경 확대 [<a href="#ref-19">19</a>]
